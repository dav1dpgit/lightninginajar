## Asks of upstream — the pull requests to joinstr v2 (DP's list)

1. `payout_type` (P1, Tatara v0.10 §6.1): a pool may declare P2WSH payouts, so a channel's 2-of-2 can be a pool's exit.
   Phase 2's public channel pools need it upstream.
2. Silent-payment inputs (DP 2026-10-13 12:22: "let's add 2 to the ask"): joinstr v2 takes every taproot input's
   untweaked key and applies the BIP-341 tweak itself (funding.rs); a BIP-352 output's key is already final (the spend
   key plus the payment's own tweak), and no untweaked key exists whose tweak lands on it, so its ownership proof and
   signature cannot be made today. The ask: let a member register a taproot input with a key that is already the
   output key (a "tweaked: true" input, or an input type for silent-payment outputs) and sign it as such. Until then a
   silent-payment coin cannot enter a pool (LiJ says so in plain words at the coin).
